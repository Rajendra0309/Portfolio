## 🛠️ Tech Stack & Architecture

- **Structure**: Semantic HTML5 with accessibility standards (WCAG AA compliant)
- **Styling**: Vanilla CSS with custom properties, smooth transitions, and responsive layouts (breakpoints at 900px and 760px)
- **Interactions**: Vanilla JavaScript for mobile navigation, scroll-triggered reveals, scrollspy nav highlighting, and clipboard interaction
- **Zero build step**: Pure static site ready for instant deployment

---

## 🚀 Featured Projects

- **MorphDrop**: 100% offline Android document toolkit & file converter (Kotlin, Material 3, Apache PDFBox, Room, MVVM).
- **Offline AI Voice Assistant**: Fully offline personal voice assistant with on-device speech-to-text, reasoning, and synthesis (Python, faster-whisper, Ollama, Coqui XTTS v2, FAISS).
- **RaktBandhan AI**: AI-powered blood donation & transfusion coordination platform (React 18, Python, XGBoost, AWS).
- **RevBookMyShow**: Full-stack MERN movie ticket booking platform with Razorpay and AWS S3.
- **Campus Connect**: Full-stack campus collaboration platform containerized with Docker and GitHub Actions CI/CD.
- **App Health Deployment Tracker**: DevOps showcase with Docker, GitHub Actions, AWS EC2/EKS, and Terraform.

## 💻 Local Development

Run with any local HTTP server:

```bash
# Clone the repository
git clone https://github.com/Rajendra0309/Portfolio.git
cd Portfolio

# Start a local static server
python3 -m http.server 8000
# Open http://localhost:8000 in your browser
```
